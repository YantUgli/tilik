# contracts/

Kontrak data TILIK versi 1.0 (tag `contracts-v1.0`): JSON Schema draft 2020-12 untuk `Finding`, `LayerResult`, `AnalysisResult`, respons tiap endpoint, error, output LLM/VLM, dan satu aturan YAML, ditambah `openapi.yaml` (OpenAPI 3.1) yang merujuk file-file skema tersebut; `examples/` berisi contoh `*.valid*.json` yang wajib lolos dan `*.invalid.<alasan>.json` yang wajib ditolak skema bernama sama. Kontrak ini **dibekukan**: lane WEB, API, dan DATA hanya membacanya (model Pydantic dan tipe TypeScript diturunkan dari sini, bukan sebaliknya), dan perubahan apa pun hanya dilakukan oleh Ayen lalu diumumkan ke semua lane. Jalankan tes kontrak dari akar repo dengan `uv run --project services/api pytest services/api/tests/test_contracts.py` (atau `cd services/api && uv run pytest tests/test_contracts.py`).
